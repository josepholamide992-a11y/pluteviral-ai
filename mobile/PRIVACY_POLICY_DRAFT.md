## Information handled by this beta
The app stores content project topics, scripts, captions, hashtags and video-job metadata locally on your device. It stores the configured MoneyPrinterTurbo API key using your device's secure-storage facility on native mobile. The browser preview does not persist the key between sessions. If a MoneyPrinterTurbo server is connected, the app transmits the content that you choose to submit to that server for script generation, captions and video rendering. The rendering server and configured third-party AI, speech, video or stock-media providers may process the submitted content.

## What has NOT been implemented
There is no end-user account system, cloud project synchronization, advertising tracking, automated social publishing, payment collection or self-service account deletion in this build. The provider's own log and artifact retention behaviour depends on the server you configure.

## Future requirements
Before distributing this app to customers, document the actual data controller/processor roles, provider names and locations, international data transfers, specific legal basis, retention periods, rights requests, security safeguards, cookie/analytics use, and support channels. Implement an authenticated deletion workflow for remotely stored projects and outputs. Do not claim content is private from vendors unless the vendor contracts, configuration and testing support that claim.
